1. Direct Referral කියන්නේ මොකක්ද?

User A ගේ referral link එක use කරලා User B register වුණොත්:

User A → User B

මෙතන User A කියන්නේ User B ගේ Direct Sponsor. User B කියන්නේ User A ගේ Level 1 referral.

2. Referral Chain එක දිගට යන හැටි

User B ගේ referral link එක use කරලා User C register වුණොත්:

User A → User B → User C

User C ට බලද්දී:

Level 1 = User B Level 2 = User A

User A ට බලද්දී:

Level 1 = User B Level 2 = User C

3. තවත් User කෙනෙක් Register වුණොත්

User C ගේ referral link එක use කරලා User D register වුණොත්:

User A → User B → User C → User D

User D product එකක් හෝ ad එකක් buy කළොත් commission යන්නේ උඩට:

User C = Level 1 User B = Level 2 User A = Level 3

Buyer වෙන User D ට commission ලැබෙන්නේ නැහැ.

4. Product Buy එකකදී Commission යන හැටි

උදාහරණයක් ලෙස:

එතකොට distributable commission pool එක:

R100 × 20% = R20
Upline User Level Admin Percentage Payout

5. Ad එකකදී Commission යන හැටි

User D paid ad එකක් create කරනවා.

Ad Amount = R100 Admin Ad Pool = 20% Commission Pool = R20

Admin ad එක approve කරලා Active කළාම commission pay වෙනවා:

User C = Level 1 = R8.00 User B = Level 2 = R6.00 User A = Level 3 = R2.50

Ad එක reject වුණොත් commission pay වෙන්නේ නැහැ.

6. Admin Panel එකෙන් Change කළොත්

Admin Level 1 percentage එක 40% සිට 50% දක්වා change කළොත්, ඒ අලුත් value එක use වෙන්නේ ඉදිරියේදී වෙන product/ad commissions වලට පමණයි.

Old purchases/ad payouts වෙනස් වෙන්නේ නැහැ New purchases/ad payouts විතරයි change වෙන්නේ

Admin Level 6 add කළොත්, user side එකේත් Level 6 show වෙනවා.
