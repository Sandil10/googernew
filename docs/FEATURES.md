# Features

## Authentication

- User registration.
- User login.
- JWT authentication.
- Profile retrieval and updates.
- Profile picture upload.
- Password verification and password changes.
- Username availability checks.
- Shipping address updates.

## Social Posts

- Create, view, update, and delete Googer posts.
- Like and unlike posts.
- Add and delete comments.
- Share tracking.
- View tracking.
- Post reporting.
- User subscription and follow-style interactions.

## Profiles

- Public profile viewing.
- Profile view tracking.
- Follower and following lists.
- Blocked user list.
- Profile subscriptions.
- Profile edit modal.

## Marketplace

- Product listing and product detail views.
- Product creation with multiple images.
- Product editing and deletion.
- Product status updates.
- Product code lookup.
- Product likes, comments, shares, and views.
- Promoted product display.

## Cart

- Add products to cart.
- Update cart item quantity.
- Remove cart items.
- Clear cart.
- Cart sidebar UI.

## Orders

- Single order creation.
- Bulk order creation.
- Buyer order history.
- Seller order history.
- Order status updates.
- Group order status updates.
- Group order cancellation.
- Order reporting.

## Wallet

- Wallet balance access.
- User search for transfers.
- Direct transfers.
- Transfer requests.
- Pending request management.
- Transfer acceptance and rejection.
- Transaction cancellation.
- Order payment.
- Transaction history.
- Top-up, withdrawal, and coin management pages.

## Chat

- Conversation list.
- Direct messages.
- User presence updates.
- Call start, accept, reject, and completion.
- Call history and summaries.
- Call signaling support.

## Ads

- Photo and video ad campaigns.
- Product promotion campaigns.
- Profile promotion campaigns.
- Ad creation with image uploads.
- Ad editing.
- User ad listing.
- Global ad listing.
- Ad interaction and second-view UI.

## Deployment

- Next.js production build scripts.
- Backend start and development scripts.
- Combined frontend and backend development script.
