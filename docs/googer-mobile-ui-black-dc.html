Googer Mobile UI Deck

Black-background mobile screens based on the current Googer web app.

This deck follows the existing Googer customer-facing structure already present in the web app: home feed, shop, product detail, chats, wallet, profile, settings, and ad campaign flows. It is prepared as a standalone HTML review file so the client can approve screens directly or export each frame as images.

Base theme: Pure black
Reference shell: Current mobile responsive web app
Primary nav: Home / Shop / Wallet / Chats
Format: Review deck / screenshot-ready
Included

12 high-priority mobile screens covering the main customer journey.

Recommended client handoff flow: review this file first, then export approved frames into PNG if needed.

Source route families used for alignment: `/home`, `/shop`, `/product/[shareCode]`, `/chats`, `/wallet`, `/profile`, `/dashboard/settings`, `/dashboard/ad-campaign/*`.
